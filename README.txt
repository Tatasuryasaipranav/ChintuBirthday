CHINTU'S 15TH BIRTHDAY WEBSITE

Files:
- index.html: website content
- style.css: responsive cinematic blue/neon design
- script.js: photo gallery, secret message, confetti, wish button, original synthesized melody
- assets/: 5 selected photos (original photo numbers 1, 2, 5, 8, and 10)

PREVIEW LOCALLY:
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Click “Play a little music” to start the original generated birthday melody. Browsers require a click before sound can play.

PUBLISH ONLINE FOR A SHAREABLE LINK (FREE OPTIONS):
Option A — Netlify Drop:
1. Open https://app.netlify.com/drop
2. Sign in if prompted.
3. Drag the extracted chintu-website folder (the folder containing index.html) into the drop area.
4. Wait for deployment and copy the generated website URL. You can share it on WhatsApp.

Option B — GitHub Pages:
1. Create a GitHub repository and upload the contents of this folder (index.html, style.css, script.js, assets folder).
2. Open repository Settings → Pages.
3. Select Deploy from a branch, choose the main branch and root folder, then Save.
4. Wait for the Pages URL to appear.

MUSIC:
This website includes a small original synthesized melody so it works without external music links. If you want a specific song, use a song file you have permission to use and add an audio player to the page. Do not publish copyrighted music without the necessary permission.

PRIVACY:
All supplied photos are bundled locally with the website. When you publish it online, anyone with the link may be able to view those photos, so only publish pictures you are comfortable sharing.
